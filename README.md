# 🌾 ई-उपार्जन Pro (Kisan Mandi Procurement Portal)

A multi-page agricultural procurement web application designed to eliminate long farmer waiting lines, streamline vehicle inflow via slot tokens, provide transparent quality assessments, and enable live tracking of DBT bank disbursements.

## ✨ Features
- **Arrival Slot Booking:** 1-hour window reservations based on mandi capacity.
- **Live Mandi Queue & Token Tracking:** Real-time stage progress (`Slot Reserved` ➔ `Gate Entry` ➔ `QC Check` ➔ `Weighbridge` ➔ `DBT Paid`).
- **Mandi Operator Console:** Gatekeepers and weighbridge operators can approve moisture limits and log gross/tare weights.
- **MSP Rates & Payout Calculator:** View official crop rates and calculate estimated revenue.
- **DBT Settlement Ledger:** Track electronic disbursements via PFMS.
- **Grievance Redressal Cell:** Dispute resolution for quality deductions or delays.
- **Persistent Data:** Powered by browser `localStorage` to synchronize states across all pages.

## 🛠️ Tech Stack
- HTML5
- CSS3 (Responsive, Glassmorphism, Theme-styled)
- Vanilla JavaScript (Local State & Session Management)
